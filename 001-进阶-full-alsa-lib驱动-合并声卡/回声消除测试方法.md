你这批命令里，**播放 `cap_out.pcm` 时使用 `-c 1` 是对的**，因为它们是 `out_ch=1` 生成的文件。但旧文件的内容不明确，先统一测试音源和目录。

另外，`--output /app/sd/vqe_playback` 后若直接换行、没有 `\`，下一行的 `--vqe_enable` 不会生效。

**先不改 `asound.conf` 和 JSON，按下面流程测试。现场说的话与录音内容相似，不一定会被消除，AEC 根据波形关系处理；测试时说不同内容更容易判断。**

### 1. 制作确定的播放音源

停止其他录音程序、关闭喇叭播放，执行：

```
mkdir -p /app/sd/aec_check
arecord -D plughw:1,0 -t wav -f S16_LE -r 16000 -c 1 \
  -d 10 /app/sd/aec_check/source.wav
```

这 10 秒说：“这是喇叭播放的测试音，一二三四五……”
它从 PDM 麦克风录制单通道 WAV，不包含参考音通道。先试听，确认有清晰声音：

```
./aplay -D speaker_playback /app/sd/aec_check/source.wav
```

### 2. 固定录音参数

在当前终端定义下面的函数。首次使用 `vqe_enable=1`，让模块开关按 JSON 配置；`2` 分支会额外显式启用多个模块，稍后再单独对比。

```
rec_vqe() {
  mkdir -p "/app/sd/aec_check/$1"
  ./rk_mpi_ai_test --sound_card_name=vqe_capture \
    --device_rate 16000 --device_ch 3 \
    --out_rate 16000 --out_ch 1 \
    --output "/app/sd/aec_check/$1" \
    --vqe_enable 1 --vqe_cfg /app/config_aivqe.json
}
```

每次录音约 15 秒后按 `Ctrl+C`，再进行下一项：

| 测试            | 命令与操作                                                   | 预期                     |
| --------------- | ------------------------------------------------------------ | ------------------------ |
| A：只有现场人声 | 执行 `rec_vqe near`，不播放音源，对麦克风说话                | 人声清晰保留             |
| B：只有喇叭声音 | 后台播放音源，再执行 `rec_vqe far`，现场保持安静             | 播放回声明显降低         |
| C：同时说话     | 后台播放音源，再执行 `rec_vqe both`，现场说“六七八九十”等不同内容 | 保留现场人声、压低播放声 |

B、C 两项分别用下面两组命令启动播放和录音：

```
./aplay -D speaker_playback /app/sd/aec_check/source.wav &
rec_vqe far
./aplay -D speaker_playback /app/sd/aec_check/source.wav &
rec_vqe both
```

### 3. 分别试听结果

```
./aplay -D speaker_playback -t raw -f S16_LE -r 16000 -c 1 /app/sd/aec_check/near/cap_out.pcm
./aplay -D speaker_playback -t raw -f S16_LE -r 16000 -c 1 /app/sd/aec_check/far/cap_out.pcm
./aplay -D speaker_playback -t raw -f S16_LE -r 16000 -c 1 /app/sd/aec_check/both/cap_out.pcm
```

**A 有人声、B 接近静音、C 保留现场人声，才符合目标。** B 静音本身不是异常。

### 4. 如果 A 或 C 仍然没声音

停止 MPI，录制未经 VQE 处理的三路输入：

```
arecord -D vqe_capture -t wav -f S16_LE -r 16000 -c 3 \
  -d 15 /app/sd/aec_check/input3.wav
```

先只现场说话，再播放音源。电脑上逐通道检查：CH0、CH1 应有现场人声；CH2 在不播放时应接近静音，播放时才出现参考音。

**若 CH2 明显包含现场人声，优先查参考通道；若三路输入正确而 A 仍静音，优先查 VQE 模块和参数。** 先记录 A、B、C 哪项有声，便能避免继续盲目切换通道。
